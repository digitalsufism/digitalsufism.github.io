A Bibliography of Primary Sources on Early Sufism

The following bibliography presents the Arabic sources that are extant or largely reproduced in later writings by the earliest Sufis or “proto-Sufis” who were active before or contemporary with ʿAbd al-Karīm al-Qushayrī (d. Nishapur, 465/1072). In total, this corpus comprises works, treatises, and fragments by authors who were active during the period ranging from the beginning of the third/ninth century to the middle of the fifth/eleventh century. The focus on these early Arabic sources is important for three reasons.

First, the rate of publication of Arabic sources on early Sufism has increased dramatically over the past thirty years. Many of the works that appear in this bibliography - especially those from the fourth/tenth and early fifth/eleventh centuries – were documented by Fuat Sezgin (d. 2018) in the first volume of his monumental Geschichte des arabischen Schrifttums (Leiden: Brill, 1967). However, there is no comprehensive, up-to-date record of the availability of these works in published editions, and some additional material has been located subsequent to Sezgin’s study.

Second, many of the works that appear in this bibliography are based on relational data. That is, the authors explicitly identify the source of quotes or, even more significantly, preface quotations with extensive “pathways of transmission” (Ar. asānīd; sg. isnād). The value of these relational data for better describing the dynamics of early Sufi activity has been remarked upon by Sara Sviri: “The formative period of Islamic mysticism cannot be properly described without an attempt to map the affiliations that connected individual mystics of this period to one another.”

Finally, drawing attention to these early works and their relational data is especially appropriate in light of the criticisms of “neo-skeptical” scholarship as it has been applied to the analysis of early Sufism.

allWorks = bibliography.authors.flatMap(author =>

    deathLocation: author.deathLocation,
    hasEditions: work.editions && work.editions.length > 0,
    hasTranslations: work.translations && work.translations.length > 0,
    hasManuscripts: work.manuscripts && work.manuscripts.length > 0,

viewof centuryFilter = Inputs.select(

  {label: "Century:", value: "All"}
)

viewof typeFilter = Inputs.select(
  ["All", "discursive", "isnad", "reconstruction", "uncertain"],
  {label: "Work Type:", value: "All", format: x => x === "All" ? "All Types" : x === "isnad" ? "Isnād-based" : x.charAt(0).toUpperCase() + x.slice(1)}
)

viewof availabilityFilter = Inputs.select(
  ["All", "has-editions", "has-translations", "has-manuscripts", "has-commentary"],
  {label: "Availability:", value: "All", format: x => ({
    "All": "All Works",
    "has-editions": "Has Editions",
    "has-translations": "Has Translations",
    "has-manuscripts": "Has Manuscripts",
    "has-commentary": "Has Scholarly Commentary"
  })[x]}
)

// Apply filters - start with all works, then apply filters and search
filteredWorks = {
  let works = allWorks;

  // Apply dropdown filters first
  if (centuryFilter !== "All") {
    works = works.filter(w => w.century === centuryFilter);
  }

  if (typeFilter !== "All") {
    works = works.filter(w => w.type === typeFilter);
  }

  if (availabilityFilter === "has-editions") {
    works = works.filter(w => w.hasEditions);
  } else if (availabilityFilter === "has-translations") {
    works = works.filter(w => w.hasTranslations);
  } else if (availabilityFilter === "has-manuscripts") {
    works = works.filter(w => w.hasManuscripts);
  } else if (availabilityFilter === "has-commentary") {
    works = works.filter(w => w.hasCommentary);
  }

  // Apply search term filter if present
  if (searchTerm && searchTerm.trim() !== "") {
    const searchStr = searchTerm.toLowerCase().trim();
    works = works.filter(work => {
      return (
        work.authorName.toLowerCase().includes(searchStr) ||
        work.title.toLowerCase().includes(searchStr) ||
        (work.titleTranslation && work.titleTranslation.toLowerCase().includes(searchStr)) ||
        (work.scholarlyCommentary && work.scholarlyCommentary.toLowerCase().includes(searchStr)) ||
        work.editions.some(ed => ed.citation.toLowerCase().includes(searchStr)) ||
        work.translations.some(tr => tr.citation.toLowerCase().includes(searchStr))
      );
    });
  }

  return works;
}

Work Type Legend

Discursive Works Epistles (rasaʾil) and most topical works. If a work has never been described, it is filed to this default setting.

Isnād-based Works Works composed (largely) using isnāds; this includes, but is not limited to, works on ḥadīth.

Reconstruction (Source[s]) Works that have been reconstructed by modern scholars. Information about the source or sources of reconstruction is given after the title, between parentheses.

Uncertain Attribution (attr.) Works that are fragmentary, show evidence of multiple layers of redaction, or which may have been excerpted from later sources; all works of this type are marked with the abbreviation attr.
